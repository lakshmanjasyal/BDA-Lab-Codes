# BDA Lab Codes

Programs for Big Data Analytics laboratory exercises using R, Python, and
PySpark.

## Contents

- R programs for numerical operations, matrices, preprocessing, regression,
  clustering, KNN, and market basket analysis
- PySpark programs for RDDs, DataFrame operations, and word count
- Input datasets and text files used by the programs
- `BDA_Lab_Programs.tex`, which documents the experiments

## Requirements

- R with the packages used by the R programs
- Python 3 with PySpark for the Spark programs
- Java and Apache Spark for local PySpark execution

Run each program from this directory so that relative input paths such as
`iris.csv` and `input.txt` resolve correctly.
